# DB 표준 점검 — 사용자 매뉴얼

## 1. 개요

| 항목 | 내용 |
|------|------|
| **프로그램명** | DB 표준 점검 도구 |
| **URL** | `/apps/chk-db-std` |
| **목적** | 행정안전부(MOIS) **공통표준단어·용어·도메인·코드**와 설계서(Excel)의 일치 여부 점검 |
| **표준 사전** | MOIS 기본 CSV (서버 번들) 또는 사용자 CSV 업로드 |

![DB 표준 점검 UI](./images/manual-chk-db-std-ui.png)

## 2. 화면 구성

### 2.1 제목과 샘플 데이터

- 상단에는 **DB 표준 점검 도구** 제목과 설계서 업로드·Excel 결과 다운로드 안내가 표시됩니다.
- **샘플 데이터** 영역에서 현재 점검 종류에 맞는 테이블정의서 샘플을 내려받습니다.

### 2.2 점검 실행

화면의 **종류** 선택값에 따라 테이블정의서 또는 코드정의서 입력이 전환됩니다. 테이블정의서는 표준단어·표준용어·표준도메인 점검에 공통으로 사용하고, 표준코드는 코드정의서 Excel을 사용합니다.

| UI 요소 | 기능 |
|---------|------|
| **종류** | 표준단어·표준용어·표준도메인·표준코드 중 선택 |
| **설계서 Excel / 코드정의서 Excel** | 선택한 종류에 맞는 `.xlsx` 업로드 |
| **정의서 시트** | 파일 시트를 확인하고 대상 시트를 선택. 한 시트면 자동 선택될 수 있음 |
| **파일 사전 확인** | 형식과 점검 가능 여부를 실행 전에 표시 |
| **표준 CSV (선택)** | 화면 안내에 따라 단어·용어·도메인 CSV를 업로드. 미업로드 항목은 서버 기본 사전을 사용 |
| **점검 실행** | 선택한 종류와 입력 파일로 점검 시작 |
| **결과 Excel 다운로드** | 현재 점검 결과를 Excel로 저장 |
| **단어집 다운로드** | 점검에서 사용한 표준단어·용어와 미등록 후보를 내려받음 |

### 2.3 점검 결과

점검이 끝나면 실행 영역 아래에 결과가 표시됩니다.

| 영역 | 설명 |
|------|------|
| **통계** | match / review / unmatch 건수 |
| **결과 탭** | 일치 / 검토 / 미매칭 |
| **검색·페이지 이동** | 결과 행을 검색하고 페이지 단위로 확인 |
| **결과 표** | 입력 컬럼과 표준 후보, 상태·비고를 행별 표시 |

#### 결과 탭

| 탭 | 의미 |
|----|------|
| **일치 (match)** | 표준과 완전 일치 |
| **검토 (review)** | 부분 일치 — "영문 불일치만" 필터 가능 |
| **미매칭 (unmatch)** | 표준에 없음 |

### 2.4 표준용어 생성

화면 아래쪽의 **표준용어 생성** 영역에 한글명을 줄 단위로 입력해 표준용어와 영문 약어를 조회합니다. 결과에는 표준용어 일치·단어 조합·검색 결과 없음이 구분되고, 권장 영문명을 복사할 수 있습니다. 점검에 사용자 CSV를 올렸다면 해당 사전을 생성에도 적용할 수 있습니다.

## 3. 점검 종류 (kind) 상세

| kind | 입력 파일 | 점검 내용 |
|------|-----------|-----------|
| **word** | 테이블정의서 Excel | 컬럼·속성명이 **공통표준단어**에 있는지 |
| **term** | 테이블정의서 Excel | **공통표준용어** (한글명·영문약어) |
| **domain** | 테이블정의서 Excel | **공통표준도메인** (데이터 타입·길이) |
| **code** | 코드정의서 Excel | **공통표준코드** 값 |

---

## 4. 작동 방식

```
Excel 업로드 → validate (형식·시트 자동 감지)
    → (선택) 사용자 CSV 또는 MOIS 기본 사전 로드
    → kind별 매칭 엔진 실행
    → match / review / unmatch 분류 + stats
    → (캐시) 동일 파일+kind면 재실행 생략 가능
    → JSON 결과 → UI / xlsx export
```

**설계서 형식 자동 감지:** 목록형, 블록형, 코드정의서 등 여러 양식 지원.

---

## 5. 사용 방법 (단계별)

### 5.1 표준단어 점검

1. **점검 종류** → **word** 선택
2. 테이블정의서 `.xlsx` 업로드 → 검증 메시지 확인
3. **점검 실행**
4. 결과의 **검토**·**미매칭** 탭에서 보완할 항목 확인
5. **결과 Excel** 다운로드

### 5.2 DBManager에서 넘어온 경우

1. DBManager **설계서 → 스크립트** 탭에서 **DB 표준 점검으로** 클릭
2. 설계서가 자동 handoff (`?from=db-manager`, IndexedDB)
3. kind 선택 후 **점검 실행**

### 5.3 표준용어 생성

1. 하단 **표준용어 생성**에 한글 컬럼명 입력 (한 줄에 하나)
2. **생성** 클릭
3. **exact**면 표준용어 그대로 사용, **composed**면 단어 조합 권장 영문명 참고

---

## 6. 입력·출력

| 구분 | 형식 |
|------|------|
| **입력** | `.xlsx` 테이블정의서 또는 코드정의서; optional `.csv` 표준 |
| **출력 (화면)** | match[], review[], unmatch[], stats |
| **출력 (파일)** | `chkdbstd_{kind}_result.xlsx`, word-dict.xlsx, term-dict.xlsx |

---

## 7. 환경 요구사항

- API 모듈: `apps/api/chkdbstd/`
- MOIS CSV + code index (`pkl`) 서버 번들
- `CHKDBSTD_DIR` (선택) — 표준 파일 경로 override

## 8. ER Modeler·DBManager와의 관계

![워크플로 개요](./images/manual-workflow-overview.png)

| 흐름 | 설명 |
|------|------|
| Excel 설계서 → **DB 표준 점검** | 명명·도메인 표준 준수 확인 |
| Excel → **DBManager** | DDL 생성·DB 적용 |
| Excel → **ER Modeler** | ERD 편집 후 다시 Excel export → 표준 점검 |

동일 **테이블정의서 Excel 양식**을 공유합니다.
