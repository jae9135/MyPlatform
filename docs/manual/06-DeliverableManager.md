# DeliverableManager — 사용자 매뉴얼

## 1. 개요

| 항목 | 내용 |
|------|------|
| **프로그램명** | DeliverableManager |
| **URL** | `/apps/deliverable-manager` |
| **목적** | SI/PMO **산출물 목록** 조회 — 단계·활동별 산출물·양식·참고자료 카탈로그 |
| **상태** | 공개 테스트용 — 실제 문서 본문은 회사 PC·Storage placeholder |

## 3. 기능 상세

### 3.1 카탈로그 데이터

| 항목 | 설명 |
|------|------|
| **출처** | Supabase Storage `catalog.json` |
| **seed** | `supabase/seed/deliverable-manager/` |
| **읽기 전용** | 사용자가 목록 구조를 UI에서 편집하지 않음 |

### 3.2 문서 종류 (document kind)

| kind | 버튼 라벨 | 의미 |
|------|-----------|------|
| `deliverable` | **산출물** | 본 산출물 문서 |
| `template` | **양식** | 작성 양식 |
| `reference` | **참고** | 참고 자료 |

한 행에 여러 파일이 있으면 **파일 선택 picker** 후 미리보기.

### 3.3 작성 상태 (로컬만)

| 상태 | 표시 | 저장 |
|------|------|------|
| 미착수 | none | — |
| 작성중 | wip | localStorage |
| 완료 | done | localStorage |

**작동 방식:** 상태 버튼 클릭 시 none → wip → done 순환. **서버 동기화 없음** — 기기·브라우저별.

### 3.4 미리보기·다운로드

| 기능 | 설명 |
|------|------|
| **미리보기 modal** | Storage placeholder 텍스트 표시 |
| **다운로드** | placeholder를 `.txt`로 저장 |

실제 Word/PDF는 회사 환경·Storage에 별도 관리.

---

## 4. 사용 방법 (단계별)

1. `/apps/deliverable-manager` 접속
2. **사업관리** 또는 **개발관리** 탭 선택
3. **단계**·**상태**·**검색**으로 목록 필터
4. 행의 **산출물** / **양식** / **참고** 클릭 → 미리보기
5. 작성 진행 시 **상태** 버튼으로 wip/done 표시 (본인 진행 관리용)

---

## 5. 입력·출력

| 구분 | 형식 |
|------|------|
| **입력** | 없음 (조회 전용) |
| **출력** | placeholder `.txt` 다운로드 |
| **로컬 상태** | localStorage JSON |

## 7. 주의사항

- **실문서 저장소 아님** — PMO 체크리스트·목록 뷰어 성격
- 작성 상태는 다른 PC와 공유되지 않음
- catalog 없으면 빈 목록 — Supabase seed·업로드 확인
