# 홈페이지 색상·구조 시안

현재 공개 홈(`apps/portal`)은 **다크 + cyan** 톤입니다.  
아래 HTML 시안은 **밝고 친화적인** 대안입니다. **[index.html](./index.html)** 을 브라우저에서 열어 4개를 비교한 뒤, 번호를 알려주시면 Next.js에 반영합니다.

| 시안 | 파일 | 특징 | 추천 대상 |
|------|------|------|-----------|
| **A** | [01-밝은-포털형.html](./01-밝은-포털형.html) | 흰 배경 + 파란 포인트, **카드 그리드** 한눈에 | 처음 방문, 비개발자, 공공·SI 담당자 |
| **B** | [02-소프트-스카이.html](./02-소프트-스카이.html) | 하늘색 그라데이션 Hero, **넓은 여백** | 데모·랜딩, “가볍게 둘러보기” |
| **C** | [03-웜-퍼블릭.html](./03-웜-퍼블릭.html) | 따뜻한 회색 + **네이비·그린**, 공공기관 친화 | 행정·감리·품질 점검 강조 |
| **D** | [04-소프트-인디고.html](./04-소프트-인디고.html) | 연한 인디고, **아코디언 도구 목록** 유지 | 지금 구조 유지 + 밝게만 |

## 공통 구조 (모든 시안)

1. Hero — 가치 제안 + CTA (도구 체험 / 맞춤 문의 / 사내 포털)
2. 통계 — 7종 프로그램 · 3분류
3. **플랫폼 7종** (ReceiptToPDF 제외)
4. **ReceiptToPDF** 별도 섹션
5. 워크플로 (설계서 → DB)
6. 맞춤 개발 CTA
7. Footer

## 선택 시 알려주실 내용

- 선호 시안 번호 (A/B/C/D 또는 혼합: 예 “B Hero + C 색상”)
- 헤더: 밝은 흰색 vs 연한 색 바
- 도구 영역: **카드 그리드(A,B)** vs **펼침 목록(D)**
- 포인트 색: 파랑 / 하늘 / 그린 / 인디고

## 현재 구현과의 관계

- 시안은 **정적 HTML** (선택용). 확정 후 `app/marketing.css` 및 `components/marketing/*`에 적용합니다.
- 사내 `/login` · `/workspace` · `/apps/*` 는 시안 확정 후 **동일 톤으로 맞출지** 별도 결정 가능합니다.
