태그 품질관리, 업무자동화, 소프트웨어품질, 웹접근성, DB표준, WBS, MyPlatform

요약 소스·웹·성능 진단부터 DB 설계와 프로젝트 일정 관리까지, MyPlatform의 도구 구성과 각 도구의 사용 범위를 살펴봅니다.

아래 본문을 복사해 티스토리 글쓰기 화면에 붙여넣으세요. 게시 제목과 카테고리, 태그는 티스토리 설정란에 각각 입력하면 됩니다.

품질관리나 프로젝트 관리를 하다 보면 소스코드 점검, 웹 화면 확인, DB 설계 검토, 일정 관리 도구를 각각 찾아 쓰게 됩니다. MyPlatform은 이런 작업을 브라우저에서 열 수 있는 여러 업무 도구로 묶은 플랫폼입니다.

한 번의 실행으로 모든 품질 업무를 자동 처리하는 제품은 아닙니다. 업무에 맞는 도구를 골라 쓰는 포털이며, 도구마다 입력 방식과 실행 환경, 제공 범위가 다릅니다. 이 글에서는 현재 공개된 8개 플랫폼 도구를 어떤 상황에 쓸 수 있는지 살펴봅니다. MyPlatform 홈페이지와 도구 목록 보기

품질·진단 도구 3가지

1. 소스코드·보안 진단

프로젝트 ZIP을 등록해 소스코드의 품질·보안 관련 점검 결과를 확인하는 도구입니다. 결과에는 스캐너별 상태와 발견 항목, 이전 실행과의 비교, 제공되는 보고서 내보내기 기능이 포함될 수 있습니다. 실제 실행 가능한 분석기는 서버에 설치된 도구와 ZIP 안의 프로젝트 구성에 따라 달라질 수 있습니다.

소스코드 진단 소개 · 소스코드 진단 열기

2. 웹 품질 진단

현재 화면에는 IPMS(추가 암호 필요), 정적 소스, 외부 URL 화면 진단 모드가 있습니다. 정적 소스 모드에서 Java/WAR ZIP을 입력할 수 있고, 외부 URL은 등록된 대상에 한해 화면 점검을 진행합니다. 자동 점검은 사람이 판단해야 하는 대체 텍스트의 적절성이나 키보드만으로 실제 과업을 끝낼 수 있는지까지 대신 판정하지 않습니다.

웹 품질 진단 소개 · 웹 품질 진단 열기

3. 성능 진단

Locust로 HTTP 부하를 발생시켜 요청 처리량, 응답시간, 오류율 등을 확인합니다. 동시 사용자 수와 실행 시간 같은 조건을 설정하고 결과를 살펴볼 수 있습니다. 현재 구성에서는 로컬 API와 Locust 실행 환경이 필요할 수 있으며, 부하는 권한이 있는 테스트 대상에만 실행해야 합니다.

DB·설계 도구 3가지

4. DB 표준 점검

샘플 또는 테이블정의서 Excel을 준비하고 단어·용어·도메인·코드 점검 종류를 선택해 표준 항목을 확인합니다. 결과에서 일치·검토·미매칭 항목을 살펴보고, 화면에 있는 표준용어 생성 영역에서 후보를 만들 수 있습니다.

DB 표준 점검 소개 · DB 표준 점검 열기

5. DBManager

현재 열려 있는 화면에서는 테이블정의서 기반 DDL 생성 작업을 할 수 있습니다. DB 적용, 데이터 관리, 역동기화 탭은 추가 암호로 잠겨 있으므로, 공개 데모에서 모든 DB 관리 기능을 사용할 수 있다고 가정하지 말고 화면의 권한 상태를 먼저 확인해야 합니다.

DBManager 소개 · DBManager 열기

6. ER Modeler

새 프로젝트는 빈 캔버스로 시작합니다. 테이블정의서 Excel이나 SQL을 가져와 모델을 구성하고, 테이블과 관계를 확인한 뒤 제공되는 검증·내보내기 기능을 이용하는 흐름입니다. 작업 프로젝트는 브라우저에 저장되므로 다른 PC에서 이어가려면 파일로 내보내 보관하는 방법을 확인하세요.

업무·프로젝트 관리 도구 2가지

7. DeliverableManager

프로젝트 산출물 목록을 단계와 검색 조건으로 찾아보는 도구입니다. 현재 공개 화면은 목록과 필터 중심이며, 데모에 연결된 문서 본문은 실제 조직 산출물이 아니라 placeholder 자료일 수 있습니다. 작성 상태는 현재 브라우저에 저장되어 팀 전체의 공동 문서 저장소처럼 동작하지 않습니다.

8. MyGantt

WBS 작업을 계층으로 정리하고 표와 간트 영역에서 계획·실제 일정, 담당자, 진행률 등을 관리합니다. Excel/JSON 가져오기·내보내기와 휴일 설정 같은 기능도 제공됩니다. 로컬 프로젝트는 브라우저 저장소에 보관되고, 공유 링크는 배포 환경의 Supabase 설정에 따라 이용할 수 있습니다.

업무 흐름에 맞춰 조합하는 예

  • 웹 품질 확인: 소스 구조나 화면을 점검하고, 자동 결과에서 판정하기 어려운 내용은 담당자가 직접 확인합니다.
  • DB 설계: 테이블정의서를 표준 점검에 활용하고, 필요하면 ERD 모델링과 DDL 생성 화면으로 이어갑니다. 잠긴 기능은 접근 권한을 확인합니다.
  • 프로젝트 계획: 산출물 목록에서 필요한 결과물을 확인하고, MyGantt에서 WBS와 일정을 구성합니다.

각 도구가 하나의 자동화 파이프라인으로 모든 데이터를 자동 전달하는 것은 아닙니다. 입력 파일과 결과를 확인하면서 프로젝트에 필요한 순서를 직접 정하는 방식으로 활용하세요.

사용 전에 확인할 점

  • 프로그램은 베타로 운영되며, 실제 화면과 기능은 배포 상태에 따라 달라질 수 있습니다.
  • 소스·웹·성능 진단 등은 API 서버와 도구 설치 상태에 따라 실행 가능 범위가 달라집니다.
  • 암호로 잠긴 메뉴나 로컬 저장 기능은 공개 화면에서 안내되는 범위를 먼저 확인합니다.
  • 부하 테스트는 본인 또는 조직이 시험을 허용한 서버에서만 진행합니다.

마무리

MyPlatform은 품질 진단, DB 설계, 프로젝트 관리를 돕는 여러 브라우저 도구를 한곳에서 찾을 수 있게 구성한 포털입니다. 내 업무에 필요한 도구부터 골라 기능과 사용 조건을 확인하고, 자동화 결과와 담당자의 검토를 함께 활용하면 좋습니다.
